One line about a smartwatch that is very proud of a workout that never happened. The program writes the single line to `entry.txt` (UTF-8, 130 characters, no trailing newline).

> My smartwatch congratulated me on burning 300 calories, which is impressive considering I earned them all reaching for the remote.

## Run it

```sh
python3 main.py
```

By default the entry is written to `/output/entry.txt`. Set `MAKEFUN_OUTPUT_DIR` to write it somewhere else:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/laugh-off-out python3 main.py
```
